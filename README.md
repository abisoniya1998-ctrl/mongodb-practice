MongoDB CRUD Practice

A beginner-friendly MongoDB project demonstrating CRUD operations using MongoDB Shell and JavaScript.

Features

- Create and insert student records
- Read and filter records
- Update student and product details
- Delete records
- Practice MongoDB query operators

Technologies

- MongoDB
- JavaScript
- Node.js

How to Run

Open MongoDB Shell ("mongosh") and run:

load("C:/path/to/mongodb_practice.js")

Replace the path with the actual location of the script on your computer.
